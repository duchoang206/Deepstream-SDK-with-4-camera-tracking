# Deepstream SDK with 4 Camera Tracking

This project is a dynamic backend and Next.js frontend system for YOLO-based vision AI.

## Structure
- `backend/`: FastAPI backend and YOLO engine
- `web-dashboard/`: Next.js Web Dashboard
- `docs/`: Documentation and assets
- `services/`: External services like MediaMTX
- `models_config/`: YOLO model weights and configs
